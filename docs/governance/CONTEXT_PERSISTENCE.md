# Context Persistence

- permanent rules -> `AGENTS.md` and `docs/governance/*`
- current cross-lane facts -> `docs/context/CURRENT.md`
- current task/gate -> `TASKS.md`
- latest executable continuation -> `HANDOFF.md`
- durable product/security semantics -> `docs/contracts/*`
- historical acceptance evidence -> Git/PR/issue history and provenance docs

Do not turn this repository into a chat-history store. Do not copy private history or product-knowledge repositories into it.
